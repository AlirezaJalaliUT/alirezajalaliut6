# راهنمای انتشار نسخه ۶

۱. در حساب GitHub به آدرس `AlirezaJalaliUT` یک مخزن عمومی با نام دقیق `alirezajalaliut6` بسازید.

۲. فایل ZIP را استخراج کنید و **تمام محتویات داخلی** را مستقیماً در ریشه مخزن آپلود کنید. پوشه مادر را آپلود نکنید. `.pages.yml` باید حتماً در ریشه باشد.

۳. در Settings → Pages، گزینه Deploy from a branch، شاخه main و مسیر / (root) را انتخاب کنید.

۴. سایت باید روی `https://alirezajalaliut.github.io/alirezajalaliut6/` منتشر شود.

۵. برای ویرایش بدون کدنویسی به pagescms.org بروید و مخزن را متصل کنید. همه متن‌های نمایشی سایت و فیلدهای CMS انگلیسی هستند.

توجه: سایت نسخه آزمایشی است و noindex دارد. اطلاعات تاییدنشده از جمله جوایز، پروژه‌های خاص و نام اعضای گروه با داده ساختگی تکمیل نشده‌اند.
